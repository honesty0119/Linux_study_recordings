# RK3568 QT 开发任务书

任务目标
完成 RK3568 平台 QT 开发环境搭建，编译部署 QT Demo，并在开发板上实现一个可用的 QT 串口调试助手图形应用，在板子上正常运行、串口收发数据。

## 任务 1：开发环境搭建

1. 选择开发方式：交叉编译环境 / SDK 内原生编译环境，完成主机开发环境部署（Ubuntu 开发主机）。
2. 获取适配 RK3568 的 QT 版本（如 Qt5 或 Qt6），配置交叉编译工具链、sysroot，配置环境变量，保证编译器、qmake / cmake 可以正常调用。
3. 配置板载系统：确认 RK3568 开发板文件系统已经部署对应 QT 运行库、依赖库、串口驱动，保证板子支持 QT 图形显示（LCD / HDMI）。
4. 测试环境有效性：能够识别开发板、可以将程序、资源文件传输到开发板（scp、sd 卡、adb 任选一种方式），可以远程登录开发板查看日志。

## 任务 2：基础 QT Demo 验证

1. 使用 QT Creator 创建一个基础图形 Demo 工程（例如窗口 + 按钮、标签）。
2. 使用配置好的交叉编译环境编译工程，生成适合 RK3568 架构的可执行程序。
3. 将可执行程序部署到 RK3568 开发板，设置权限，配置 QT 运行环境变量（显示插件、平台参数）。
4. 在开发板上成功启动 Demo，窗口正常渲染、按钮交互响应，无崩溃、闪退，验证整套编译 + 部署链路通。

## 任务 3：QT 串口调试助手开发需求

功能需求全部在开发板上验证：
1. 串口选择功能：自动枚举、列出开发板可用串口设备（如 /dev/ttyS*、/dev/ttyUSB*），支持下拉选择串口。
2. 串口参数配置：支持配置波特率、数据位、停止位、校验位（奇偶校验 / 无校验），配置后可以打开、关闭串口。
3. 发送区：支持输入文本，点击发送按钮向串口输出数据；支持勾选自动发送（定时循环发送）。
4. 接收区：串口收到的数据在接收窗口展示；支持 ASCII 显示、十六进制切换；支持清空接收区。
5. 附加功能：支持显示串口打开 / 关闭状态提示；增加简单的状态提示（成功、报错弹窗或状态栏）；处理串口异常（设备拔出、打开失败提示）。
6. 界面要求：界面布局简洁，适配开发板屏幕分辨率，控件布局合理，触摸 / 鼠标操作正常。

## 任务 4：编译、部署与板上测试

1. 在搭建好的交叉编译环境下编译串口助手工程，生成目标平台可执行文件。
2. 部署到 RK3568 开发板，配置 QT 运行环境，启动应用。
3. 硬件测试：使用串口回环或者外接串口模块测试：
- 串口打开、关闭正常，参数修改生效；
- 发送的数据串口可以正常输出；外部输入的数据可以在界面正常接收展示；
- 切换 ASCII / 十六进制显示正常，无乱码；
- 异常场景：串口不存在、权限不足、设备热拔插，程序不会崩溃，给出提示。
4. 记录测试结果，收集启动日志、报错日志，排查依赖缺失、平台插件问题。

## 任务 5：交付验收要求

1. 交付文档：环境搭建步骤文档，包含工具链、sysroot、环境变量配置方法，部署流程，板子 QT 环境配置说明。
2. 工程说明文档：工程创建方式、依赖说明（串口库说明，如 QtSerialPort）。
3. 验收标准
- 主机可以正常交叉编译 QT 程序；
- 基础 Demo 在板子流畅运行；
- QT 串口助手在 RK3568 开发板正常启动，所有串口功能可验证；
- 程序运行稳定，无持续闪退，串口收发数据准确。

## 任务 6：拓展可选任务（选做）

1. 增加保存接收日志到文件的功能；
2. 增加发送文件到串口的功能；
3. 适配触屏，加大控件尺寸方便触摸操作；
4. 打包脚本：一键编译 + 一键推送程序到开发板。
