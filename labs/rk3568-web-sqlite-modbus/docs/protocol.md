# Modbus TCP协议与主站接入

## 连接设置

使用Modbus TCP，端口502，Unit ID必须匹配本次启动值。无配置覆盖时默认1；验收使用7。PC工具选择FC03，PDU起始地址0、数量64。不要选RTU over TCP，也不要把40001记法当作实际PDU地址40001。

FC03保持寄存器在本应用中只读。FC04输入寄存器同样适合只读语义，但本版本保持示例FC03映射，FC04返回异常01；没有暗中更换功能码。libmodbus通用reply可处理写请求，服务端必须先执行功能码白名单，不能只靠“不提供控制输出”来保证只读。

## v2.0点表

首阶段对Wi-Fi和接口字节统计作明确扩展，映射版本为0x0200。不能用v1草案解码。所有地址为PDU零起始地址；FC03地址0在常见上位机记为40001，是否填0或40001取决于工具寻址选项。

寄存器内高字节在前，跨寄存器高字在前；无符号32位占2字，64位占4字。单次读取0–63获得一份一致快照。多段读需比较session_id和seq；采集本身是多个内核字段的顺序读取，不承诺硬件级同时采样。

| 地址 | 字段 | 说明 |
| --- | --- | --- |
| 0 | map_version | 0x0200 |
| 1 | valid_flags | bit0 carrier；bit1 IPv4；bit2信号dBm；bit3 RX字节；bit4 TX字节；bit5 RX错误；bit6 TX错误；bit7系统实时时钟已读到，**不代表已校时** |
| 2–3 | seq/u32 | 每次发布递增，可回绕 |
| 4–7 | session_id/u64 | 每次启动从内核随机源产生，识别重启 |
| 8–11 | sample_monotonic_ms/u64 | 本机单调时钟毫秒 |
| 12–15 | sample_realtime_ms/u64 | 系统实时时钟毫秒，可能未同步/跳变，不能直接用于可靠跨设备时延测量 |
| 16–17 | age_ms/u32 | 请求时计算快照年龄，超范围饱和 |
| 18 | carrier/u16 | 0断、1通；须配合有效位，Wi-Fi carrier不等于互联网可达 |
| 19 | serial_open | 固定0，表示本程序没有打开UART；不表示PuTTY关闭 |
| 20–21 | Ethernet速率保留 | 固定0，本阶段不提供有效Ethernet协商速率，不填入无线链路速率 |
| 22–23 | UART波特率保留 | 固定0，RTU未启用 |
| 24–27 | rx_errors/u64 | sysfs网卡驱动统计，非Modbus协议错误数 |
| 28–31 | tx_errors/u64 | 同上 |
| 32–35 | rx_bytes/u64 | 接口所有接收字节，不仅Modbus流量 |
| 36–39 | tx_bytes/u64 | 接口所有发送字节 |
| 40–41 | IPv4/u32 | 高字为前两个八位组，多个IPv4时选数值最小者；未知清有效位 |
| 42 | signal_dbm/i16 | 有符号二进制补码；仅驱动报告有效dBm时有效，否则为0且清bit2 |
| 43 | interface_kind | 1=具有wireless属性的接口；0=其他/未确认，不等同断言Ethernet |
| 44 | rtu_enabled | 固定0 |
| 45 | diagnostics | bit0快照超过3000ms；bit1历史功能降级；bit2历史丢弃/写入错误 |
| 46–47 | counter_epoch/u32 | 观察到驱动计数下降或ifindex变化时增加；重启由session区分 |
| 48–63 | 已定义保留字段 | 固定0 |

信号优先SIOCGIWSTATS，失败时使用有期限的iw回退；均无有效dBm时标未知，不把质量百分比误当dBm。当前不提供Wi-Fi链路速率。统计读取出现缺口时客户端须放弃跨缺口增量；仅凭离散采样不能发现所有短时复位。

## 协议处理合同

- 合法本Unit的FC03：数量1–125，范围须落在64字映射内，返回请求事务ID。
- 数量0、126或FC03长度不符：异常03。合法数量但地址/范围越界：异常02。
- 所有非FC03功能：异常01，包括0x05/06/0F/10/16/17，FC04目前也不支持。请求须先形成合法MBAP帧；拒写发生在modbus_reply前。
- 非零Protocol ID、长度小于2或大于254：关闭连接；部分帧超时关闭。错误Unit ID忽略。
- 写请求不会修改配置或寄存器镜像；Web配置API独立存在，但不改变Modbus只读边界。实时字段自然变化，不以自然变化误判写请求生效。


## C只读主站

一次读取64字，严格核对事务、Protocol ID、Unit、长度、FC03和版本。libmodbus3.2.0通用TCP确认未核验Unit，本工具用原始收发API补充检查。未知字段输出null、64位数值输出字符串、信号按有符号16位解码。

默认5轮、约1秒间隔；失败关闭连接，下轮重新连接。任何失败使最终退出码1，即使后来恢复；全成功0，参数错误2。服务器的3秒期限包括闲置等待，所以长时间不轮询可能被正常断开。TCP错误Unit忽略的处理不是RTU广播处理，RTU规则尚未实现。
