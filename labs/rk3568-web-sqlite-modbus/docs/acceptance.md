## 30分钟指标

事先固定：零错误，完整1800秒，每客户端计划读取覆盖至少95%，p95≤500ms、快照年龄≤3000ms且无过期位。实测各客户端1800次成功、一个持续连接，p50 52.10ms、p95 222.31ms、p99 382.67ms、最大846.77ms，最大年龄1010ms。

资源采样180次无缺失。预热后至1792.188秒的采样RSS均1456KiB；1802.206秒连接关闭后末次1568KiB，增加112KiB，如实保留，不判定原因或宣称证明无泄漏。平均CPU约单核0.45%，文件描述符4–8（负载期通常7，关闭后4）。本轮未冻结严格资源性能阈值，仅报告观测。
