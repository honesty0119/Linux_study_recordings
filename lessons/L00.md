## 如果目前只有 Windows PowerShell

可在 PowerShell 中执行以下只读查询，检查 WSL 是否已有可用发行版：

```powershell
wsl --list --verbose
```

若提示命令不可用、尚未安装或列出空结果，记录提示即可。此步骤不要求安装 WSL，也不要把后面的 Linux 命令直接粘贴到 PowerShell 中。

## 如果已经进入 Linux 终端

逐条执行以下只读命令，观察输出。提交输出时可隐藏用户名、主机名与私人目录名称。

```bash
uname -srm
cat /etc/os-release
printf 'Login shell: %s\n' "$SHELL"
ps -p $$ -o comm=
pwd
whoami
```

`uname` 查看内核信息；`/etc/os-release` 查看发行版信息；`$SHELL` 通常记录登录 shell，未必等于当前执行命令的 shell；`ps` 用于检查当前 shell 进程；`pwd` 显示工作目录；`whoami` 显示有效用户名。精简系统可能缺少部分文件或工具，记录实际错误以便分析。

本课无需 sudo，不安装软件，不修改系统配置。
