## 验证结果

Ubuntu x86_64、RK3568 ARM64 的静态版和动态版均通过 17/17 项检查。板端程序由 Ubuntu 配套交叉工具链生成，经 Windows COM3 传输，五个文件的 SHA-256 校验通过。

依赖检查表明：静态计算库版本不依赖 libcalc.so，动态版本依赖 libcalc.so，两者仍依赖系统 C 库。板端临时改名动态库后，静态版继续运行、动态版缺库报错；恢复后动态版通过，结果由用户文字确认。

Ubuntu 产物已实际清理并检查，板端清理由用户在 PuTTY 执行并明确确认。源码、构建规则、记录与已安装的交叉工具链保留。

## 本次纠正

- Windows 编辑、Ubuntu 编译、Windows 串口传输和开发板运行可以分别进行。
- `.a` 在链接阶段使用，运行已链接的 main_static 不需要继续保留它；计算代码已进入可执行文件。
- `-L` 与 `LD_LIBRARY_PATH` 分别用于链接时和运行时找库。
- 文件传入开发板不会自动运行，终端程序也不会弹出图形界面。
