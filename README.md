## 记录方式

每次选择一个小目标，先理解概念，再执行实验、解释结果、完成变式练习，最后更新日志和进度。日志放在 `journal/`，以日期命名；专题笔记放在 `notes/`；实验文件放在 `labs/`。

记录命令时注明操作系统、shell、工作目录及必要前提。区分预期结果与实际结果；尚未执行的实验标记为待执行。
